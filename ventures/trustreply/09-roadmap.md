# Step 9 - Roadmap
Skill: `/plan-roadmap`, `roadmap-planning`

| Window | Focus | Exit gate |
|---|---|---|
| Weeks 1-2 | Interviews (8-12) + demand page | H1-H6 verdicts; go/no-go |
| Weeks 3-4 | Accuracy probe with 5 users | pass criteria in `07-pol-probe.md` |
| Weeks 5-10 | Build MVP in priority order from `06-prioritization.md` | 3 pilot users exporting real files |
| Weeks 11-12 | Pilots, pricing test, trust page, billing | 10 paying customers (about $1.5k MRR) |
| Months 4-6 | Content + referral channels, answer library depth | $5k MRR |
| Months 7-9 | Word/PDF input, evidence attachments, team roles | $9k MRR |
| Months 10-12 | Portal assists, integrations, annual plans | $12-15k MRR |

## Tradeoffs
- Cut portals and integrations until paid demand proves them.
- Prefer shipping weekly to polishing; each release tied to a pilot user's real file.
- If gates fail, stop or pivot rather than extend the build.

## Realism check
$12-15k MRR in 12 months for a solo founder is optimistic; many such products take 18-24 months. 🔶
